### What I build

Most of my work lives in private repos, so the green squares below are the best public view of it.

- **A unified operations platform** — one system for inventory, service, finance and people across every location, with approval workflows and a help desk. Next.js, Node, Postgres, AWS.
- **In-house finance automation** — fixed-asset accounting and depreciation, invoice review with OCR, journal posting into the general ledger and e-signature workflows. Each one retired a paid tool or a manual process.
- **AI-assisted engineering** — AI code review on every pull request, automated quality and privacy gates, and living documentation the whole team works from.
- **Governed AI access (MCP)** — a Model Context Protocol server that lets approved AI assistants use business tools safely, with OAuth sign-in, per-user tokens and a full activity log.
- **Unified data &amp; marketing analytics** — sales, advertising, operations and finance data in one warehouse with one set of definitions.
- **Voice AI &amp; document intelligence** — AI on inbound calls, vision classification and OCR for paperwork.

### Also built
